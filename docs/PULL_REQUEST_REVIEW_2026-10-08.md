## Findings that block merging unchanged

1. **Node 25 is an unsuitable runtime update (#32).** The Dockerfile changes only the build stage from Node 24 to 25 while the runtime and CI remain Node 24. Node 25 is now EOL; retain the supported Node 24 line and update its digest instead. The old verification job did not build the proposed container. [Node release status](https://nodejs.org/en/about/previous-releases).
2. **CodeQL must update as a pair (#38, #39).** Each PR changes only one of `init` and `analyze`. Both actual CI logs fail with a configuration-version mismatch between 4.37.9 and 4.38.2. Combine both pins at the same upstream SHA and rerun analysis. This contribution groups future `github/codeql-action/*` updates in Dependabot to prevent the split recurring.
3. **Vitest updates are incomplete (#26, #28, #40).** #28 changes manifests without the lockfile and fails frozen installation. #26/#40 pair Vitest 5 with `@vitest/coverage-v8` 3.2.6 and fail TypeScript on missing Node globals/types. A future major upgrade must align the coverage provider, direct Node types and lockfile, then run coverage and fresh mutation checks. #42 already includes the coherent Vitest/coverage 4.1.11 update and direct Node types in all packages.
4. **Native image dependencies fail the repository's license gate (#37, #41).** Both job logs reject ten `@img/sharp-libvips-*` 1.3.4 packages under the existing deny policy. #42 removes the unused optional image processor and verifies the optimizer returns 404. Do not restore it through an old lockfile or weaken the gate. #41 still contains three independent patch updates worth retaining after regeneration.
